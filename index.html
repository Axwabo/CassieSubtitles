C.A.S.S.I.E. subtitle generator

for SCP: Secret Laboratory

  1. Type the message C.A.S.S.I.E. should announce
  2. Type the visible translation
  3. Copy the output and announce it using cassie or cassie_sl

Rich Text Cheatsheet

*This preview does not fully reflect the Rich Text shown in-game.

The trick is that we replace whitespaces of the translation with zero-width spaces which makes C.A.S.S.I.E. be unable to recognize that text as those words are treated as one long phrase.

You can use any invisible space character as the font is monospace.

Then, we hide the announcement message by wrapping it in <size=0> </size> with spaces around the message.
The spaces are crucial. Otherwise, the tag will be treated as part of the phrase, preventing C.A.S.S.I.E. from pronouncing it.

During development, this "trick" is obsolete. The game now supports custom subtitle text out of the box with the customSubtitles parameter.
